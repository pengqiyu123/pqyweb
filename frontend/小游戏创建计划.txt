非常好的问题！虽然 HTML 本身是一种标记语言，但结合 CSS、JavaScript（尤其是现代前端框架） 和 Web API，可以构建出功能强大、交互复杂、甚至媲美桌面或移动端应用的 Web 项目。以下是一些在 GitHub 上真实存在的、结构完整、功能丰富、技术栈先进的“复杂 HTML 项目”（即纯前端/静态网站项目，无需后端即可运行或演示核心功能）：

1. [Excalidraw](https://github.com/excalidraw/excalidraw)

技术栈：React + TypeScript + Canvas + 自定义渲染引擎
亮点：离线可用、PWA 支持、实时协作（通过后端插件）、完全开源

亮点：无需安装、直接操作专业设计文件

✅ 如何判断一个 HTML 项目“复杂”？

维度 简单项目 复杂项目
------ -------- --------
状态管理 全局变量 Redux/Zustand/Pinia
渲染方式 DOM 操作 Virtual DOM / Canvas / WebGL
构建工具 无 Vite / Webpack / Rollup
类型系统 无 TypeScript
测试覆盖 无 Jest + Cypress/E2E
性能优化 无 懒加载、Web Worker、缓存策略
跨平台 仅桌面 PWA + 移动适配 + 离线支持
