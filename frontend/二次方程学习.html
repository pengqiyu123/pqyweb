📐 二次方程学习

探索 y = ax² + bx + c 的奥秘，理解抛物线的特性

🏆 学习成就

y = 1x² + 0x + 0
顶点坐标
(0.00, 0.00)
对称轴
x = 0.00
y轴截距
(0, 0.00)
🎛️ 参数调节
二次项系数 a 1.0
一次项系数 b 0.0
常数项 c 0.0
🔍 原理说明
当前函数开口向上，顶点在原点，对称轴为 y 轴
顶点公式: x = -b/(2a), y = (4ac-b²)/(4a)

📝 配方法推导

① y = ax² + bx + c
② y = a(x² + (b/a)x) + c
③ y = a(x + b/2a)² - b²/4a + c
④ y = a(x + b/2a)² + (4ac-b²)/4a
